# Anonymous Person Tracking

This project explores a privacy-preserving approach to tracking people in video streams without identifying who they are.

The system detects individuals and assigns them temporary anonymous IDs, allowing movement patterns to be analyzed while maintaining privacy.

---

## Key Idea

Instead of recognizing identities (faces, names, etc.), the system focuses only on:

* Detecting people in a scene
* Tracking their movement over time
* Assigning anonymous identifiers

This ensures that useful insights can be extracted without violating personal privacy.

---

## Features

* Person detection using deep learning models (e.g., YOLO)
* Real-time multi-person tracking
* Anonymous ID assignment
* Privacy-first design (no biometric identification)
